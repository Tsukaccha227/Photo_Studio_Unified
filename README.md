# Photo Studio Unified (PWA)

これまで個別運用していた4つの写真編集PWAを1つに統合・最適化・軽量化したスタジオPWAです。

## 統合された5つのスタジオモード
1. **フレーム (`Photo_Room` / `Photo_frame` 統合)**: 外枠と中の写真の比率を個別指定可能＋位置調整、等幅/同比率フチ付け、写真から5色自動抽出、背景ぼかし、角丸・影、一括保存
2. **クロップ (`Photo_Room`)**: 縦横切替＋6比率、ズーム、ドラッグ位置調整＆3分割グリッド、写真ごとの編集保持、一括保存
3. **コラージュ (`Photo_Room`)**: 24MP (6000×4000基準) 出力、2/3/4分割16レイアウト、ドラッグ位置調整、長押し枠入れ替え
4. **カレンダー (`Photo_Calendar_Studio`)**: Exif/XMP日時自動抽出、`Nova Flat`カレンダー＆Tcロゴ合成、枠・比率・色カスタマイズ、24MP出力
5. **リソグラフ (`RisoPrint_Studio`)**: 最大3版インク、12色スウォッチ、4用紙、4網点スタイル、プリセット保存、3MP〜24MP非同期チャンク出力 (JPEG/PNG)

## デプロイ方法 (GitHub Pages)
1. ZIPを展開し、すべてのファイルをリポジトリのルートに配置します。
2. カレンダーモードで実物のTcロゴを使用する場合は、既存の `rogo.af`（または `構図.jpg`）を `index.html` と同じフォルダに置いてください（配置しない場合は内蔵ベクターロゴが自動適用されます）。
3. GitHub Pages を有効化すれば、そのままPWAとしてインストール・オフライン利用が可能です。
